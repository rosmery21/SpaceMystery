# 🚀 SpaceMystery

**SpaceMystery** è un gioco di ruolo investigativo ambientato in una stazione spaziale.

Il protagonista è **Alex**, un astronauta che deve esplorare i diversi ambienti della stazione, raccogliere indizi e pubblicare rapporti investigativi per aumentare la propria reputazione e scoprire i misteri della missione.
---

## 🚀 Come eseguire il progetto

### Prerequisiti

- Java 24
- Gradle (tramite Gradle Wrapper incluso nel progetto)

### Istruzioni

Clonare il repository da GitHub e aprire la cartella del progetto.

### Build del progetto

Su Windows:

```powershell
.\gradlew.bat build
```

Su Linux e macOS:

```bash
./gradlew build
```

### Esecuzione

Su Windows:

```powershell
.\gradlew.bat run
```

Su Linux e macOS:

```bash
./gradlew run
```

## 🎮 Come si gioca

- **WASD o frecce direzionali** — Muovi l'astronauta sulla mappa della stazione.
- **MAPPA DELLA STAZIONE** — Visualizza gli ambienti ed esplora la stazione.
- **RACCOGLI INDIZI** — Raccogli gli indizi disponibili nella stanza corrente.
- **TACCUINO INVESTIGATIVO** — Consulta gli indizi raccolti durante la missione.
- **CREA RAPPORTO** — Pubblica un rapporto investigativo utilizzando gli indizi raccolti.
- **Obiettivo** — Esplora la stazione, ricostruisci gli eventi misteriosi e aumenta la reputazione di Alex.
